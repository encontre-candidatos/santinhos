## Pendente: DivulgaCand

O NFR-041 pede conferência também com o DivulgaCand do ano antigo. A API do DivulgaCand
(`/divulga/rest/v1/candidatura/buscar/...`) segue sem responder a acesso automático, como no WP08
e no WP09 (`docs/conferencia-crescimento.md`). A comparação acima é com os arquivos de dados
abertos que o DivulgaCand também publica, não com a página.
